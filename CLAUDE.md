# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A Keycloakify v11 project (forked from keycloakify-starter) that builds custom Keycloak **login** and **account** themes in React + TypeScript. The theme name is `my-theme-gdhr`, set in `vite.config.ts` (account theme uses the `"Multi-Page"` implementation).

## Commands

```bash
yarn install                 # yarn is the declared package manager (package-lock.json also exists)
yarn start                   # Storybook on :6006 — the main way to develop/preview pages
yarn dev                     # Vite dev server (shows "No Keycloak Context" unless a mock is enabled in src/main.tsx)
yarn build                   # tsc type-check + vite build
yarn build-keycloak-theme    # build + `keycloakify build` -> dist_keycloak/keycloak-theme-*.jar (requires Maven `mvn` on PATH)
yarn format                  # prettier --write
npx eslint .                 # lint (no npm script; config in eslint.config.js)
```

There is no test suite. `tsc` (via `yarn build`) is the type check. CI (`.github/workflows/ci.yaml`) runs `build-keycloak-theme` on push/PR to `main`, and publishes the jars as a GitHub release when the `package.json` version is bumped.

To preview a specific page with `yarn dev`, uncomment the `getKcContextMock` block in `src/main.tsx` (and comment it back before building, or bundle size grows).

## Architecture

- **Entry & dispatch:** `src/main.tsx` renders `KcPage` from `src/kc.gen.tsx`, which switches on `kcContext.themeType` and lazy-loads `src/login/KcPage.tsx` or `src/account/KcPage.tsx`. `kc.gen.tsx` is auto-generated by Keycloakify (`update-kc-gen`) — do not edit it by hand.
- **Per-theme KcPage:** each `KcPage.tsx` switches on `kcContext.pageId` (e.g. `"login.ftl"`). Pages with a custom implementation are lazy-imported from `pages/`; everything else falls through to Keycloakify's `DefaultPage`. To customize another page, eject it (`npx keycloakify eject-page`) into `pages/` and add a `case` here.
- **Customized pages:** login: `Login`, `LoginResetPassword`, `LoginUpdatePassword`; account: `Account`, `Password`, `Sessions`. Each has a sibling `*.stories.tsx`.
- **Template:** `Template.tsx` in each theme is the shared page shell passed to every page (header, messages, locale switcher). `src/account/Template.backup.tsx` is an unused copy of the original.
- **Context & i18n:** `KcContext.ts` extends Keycloakify's context type (add custom properties via `KcContextExtension` / `KcContextExtensionPerPage`); `i18n.ts` builds `useI18n` and is where custom message keys go. Styling is via `main.css` per theme plus `kcClsx` class keys (`doUseDefaultCss={true}` keeps Keycloak's default CSS).
- **Stories / mocks:** `KcPageStory.tsx` in each theme wraps `createGetKcContextMock` so stories render a page via `createKcPageStory({ pageId })` with optional `kcContext` overrides.
- **Design system:** the themes mirror the gdhr-gdp-web Vue/Vuetify frontend (amber `#FFCA28` primary, Inter + Moul fonts, Khmer system name, amber footer). Shared tokens live in `src/shared/tokens.css`, brand text and logo in `src/shared/brand.ts`, plus shared icons, language picker and particles hook in `src/shared/`. Layouts are mobile-first.
- **Login styling:** the login theme runs with `doUseDefaultCss = false` (PatternFly not loaded). `src/login/KcPage.tsx` maps every Keycloak class key to a `gd-*` class styled in `src/login/main.css`; that is how DefaultPage-rendered pages (register, OTP, etc.) get the design. New pages should use `kcClsx` keys, not raw PatternFly classes.
- **Account styling:** the account theme keeps `doUseDefaultCss = true` (default pages rely on the Bootstrap 3 grid) and restyles it under `.gd-card` in `src/account/main.css`. Bootstrap sets html to 10px; that file resets it to 16px.
- **Particles background:** `src/login/Template.tsx` mounts particles.js (jsDelivr CDN) in the desktop brand panel via `useParticles`. Motion and density come from `src/config/particlesjs-config.json`; colors are overridden in the hook.
